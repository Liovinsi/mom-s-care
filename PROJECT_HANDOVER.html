Project Overview

PG Booking Platform is a premium frontend experience for browsing PG branches, viewing room details, selecting a specific bed, logging in as a guest, and entering booking information before review and payment. The product should feel elegant, trustworthy, minimal, and modern, inspired by Marriott, Hilton, Hyatt, Taj Hotels, Airbnb Luxe, and Booking.com Luxury Collection.

Core Rules

  • Frontend only.
  • Use dummy data only.
  • Do not create backend, APIs, authentication logic, validation logic, database, JWT, payment integration, or business logic.
  • Do not redesign previous pages.
  • Do not change the design language, colors, typography, spacing, or component style.
  • Create only the requested page when the user asks for a new page.
  • Do not modify previous pages unless the user explicitly asks for that.
  • Keep every page responsive for desktop, tablet, and mobile.
  • Reuse existing components where practical.

Tech Stack

  • React
  • Vite
  • Tailwind CSS
  • React Router DOM
  • Lucide React
  • Framer Motion is listed in the requested stack, but it was not installed locally when Page 5 was created. Do not add dependencies unless explicitly approved.

Design System

Style

  • Luxury hotel style.
  • Minimal, elegant, premium, modern, professional, and trustworthy.
  • Large white space.
  • Rounded cards.
  • Soft shadows.
  • Elegant typography.

Colors

  • Primary Background: #FFFFFF
  • Primary Text: #1E1E24
  • Accent: #D4AF37
  • Secondary Text: #555555
  • Border: #E5E5E5
  • Light Background: #F8F8F8
  • Success: #2E7D32
  • Warning: #F9A825
  • Danger: #C62828
  • Selected Bed Blue: #2563EB

UI Rules

  • Cards should use about 18px radius.
  • Login card used 20px radius.
  • Buttons should feel premium, rounded, and have smooth hover states.
  • Inputs should have comfortable height and gold focus border/ring.
  • Use Lucide icons.
  • Prefer real imagery for luxury pages.

Page 5 - Bed Selection

Created file: src/pages/guest/BedSelectionPage5.jsx

  • Lets users visually choose a specific bed before booking.
  • Experience is inspired by train seat booking, flight seat selection, and premium hotel room selection.
  • Includes navbar, breadcrumb, room summary, legend, interactive bed layout, selected bed panel, booking summary, sticky sidebar, empty state, loading skeleton, and footer.
  • Bed statuses: available green, booked red, reserved orange, selected blue.
  • Only available beds are clickable. One selected bed at a time.
  • Booked and reserved beds are disabled.
  • Includes keyboard focus states and tooltip text.
  • Uses dummy data only and no API calls.
  • Existing BedSelection.jsx was not modified.

Page 6 - Guest Login

Page 7 - Booking Form
